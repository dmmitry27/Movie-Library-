Movie Library (Личная кинотека)
Автор
Куликов Дмитрий

Описание
Movie Library — настольное GUI-приложение на Python для ведения личной коллекции фильмов.
Позволяет легко добавлять, просматривать и фильтровать фильмы по жанру и году выпуска, а также сохраняет данные в файл в формате JSON для последующего использования.

Возможности
Добавление фильмов с атрибутами:
Название
Жанр
Год выпуска
Рейтинг (от 0 до 10)
Просмотр всей базы фильмов в виде таблицы
Фильтрация по жанру и году выпуска
Проверка корректности ввода (год — только число, рейтинг — от 0 до 10)
Сохранение и загрузка всех фильмов в файл movies.json
Графический интерфейс с использованием Tkinter
Использование
Запустите файл main.py
(python main.py, если нужен пример команды)

Введите данные о фильме в соответствующие поля и нажмите «Добавить фильм»

Все фильмы отображаются в таблице, возможна фильтрация по жанру и году

Вся информация сохраняется в файл movies.json. При следующем запуске приложения данные загрузятся автоматически

Дополнительно

В репозитории есть файл .gitignore для исключения ненужных файлов из системы контроля версий.
Все базовые рабочие файлы (и примеры) находятся в папке проекта.
Пример


 Тест
Добавить фильм: Название – "Джентльмены", Жанр – "комедия", Год – 2019, Рейтинг – 8.6
Проверить фильтрацию по жанру "комедия" или году выпуска - 2019
